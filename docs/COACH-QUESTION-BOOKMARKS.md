# 教練提問書籤

教練頁的「我的提問書籤」自動收錄自己送出的提問，不用另外收藏。點開才讀取索引，避免增加每次切頁的等待。預設展開並固定在上方，問題文字太長以省略號顯示；點選後跳到原問題、短暫標示位置，並可閱讀附近回答。「回到最新對話」恢復近期內容。

## 較早對話

原本畫面只讀最近 50 則訊息，因此不能只用目前載入的陣列製作書籤。`GET /api/chat/bookmarks` 每次取 100 則自己的提問摘要，`before` 游標可載入更早紀錄。索引來自既有 `chat_messages`，只包含 `role=user`，不建立額外書籤表。新送出但尚未取得正式 ID 的問題也可在目前畫面定位。

如果點到尚未載入的問題，`GET /api/chat/questions/:id` 讀取該問題與附近對話（含該問題的前 16 則、後 24 則範圍），回傳原本的訊息 ID、圖片及動作明細。這是查看歷史，不會重送問題或呼叫 LLM。查看書籤期間暫停自動跳至底部與背景對話取代，避免剛定位就被拉走。送出新問題前先恢復最新對話。

## 隔離與清除

兩個端點都只讀登入者自己的資料庫，拒絕跨帳號查詢、非法編號或助手訊息定位。對話清空後索引自然清空，沒有額外殘留的收藏副本。瀏覽舊問題的上下文不會覆蓋一般切頁快取中的最新歷史。錯誤仍留在書籤區，可回到最新對話或稍後重試。

測試涵蓋超過 50 則的歷史、分頁、原問題與回答對應、助手排除、跨帳號隔離、非法 ID 及清空。手機瀏覽器另驗證點書籤定位高亮、較早上下文與返回最新對話。

書籤面板預設展開並置於教練頁最上方，維持在上緣；只讓內部清單捲動，標題不隨清單消失，可隨時點標題收起。點選問題不再自動收合面板。
