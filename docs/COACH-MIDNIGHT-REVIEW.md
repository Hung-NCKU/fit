# 教練午夜回顧

後端既有分鐘排程於 Asia/Taipei 00:00，將剛結束的前一天整理到各帳號自己的教練對話。最早回顧日期為 2026-10-15（10/16 午夜）；不補發上線前的歷史訊息。服務必須運作；離線恢復或再次讀取對話時只補前一天，不連發歷史積欠。這是對話訊息，不是手機推播。

- 飲食：當日紀錄總熱量與三大營養素，對照產生回顧時目前設定的目標，給規則式評論與下一天建議。目標並非歷史快照。
- 運動：動作、肌力組數、有氧分鐘、估計消耗 kcal；無估計的筆數另列。
- 體態：當日 weights 體態紀錄的體重、體脂、腰圍，分別比較該欄位上一次更早的有效紀錄（不使用未來紀錄）；體脂差用百分點。首次紀錄不虛構比較，沒有當日紀錄便省略。紀錄日期代表歸屬日期；午夜以後補登或修改，不回寫已送出的回顧。
- 單日波動不判定增肌減脂，不補償性禁食、不要求補做運動；特殊健康條件不自動開處方。缺少紀錄不當成沒有吃飯或運動。

實作在 server/src/coach-plan.js，重用 dailySummary 與既有私人資料庫。chat_messages 和 coach_deliveries(kind=daily_review, delivery_key=日期) 同一交易寫入；重啟、多視窗、排程與 API 同時讀取不重複。不更動真實飲食、運動、體態資料，不呼叫 Gemini，避免排隊影響每日回顧。

測試：tests/coach-plan.test.js，涵蓋台灣換日、每日唯一性、私人帳號隔離、離線補發、交易失敗回滾、體態比較與缺漏、飲食運動摘要。
