# 新版重新載入提示

每次 Vite 正式 build 自動產生唯一版號，同時注入前端與 version.json；SW 靜態快取名稱亦更新。更新部署後不要手動改版號。前端開啟時、回到前景、重新連線與每 60 秒檢查一次 version.json（no-store、獨立 query，SW 直接走網路）。網路斷線、部署中或格式不合法不強迫刷新。

版號不同顯示不可略過的重新載入提示，背景 inert，必須點「重新載入最新版」才能繼續使用。不在使用者操作到一半無預警重整；按鈕由使用者決定何時點。API 寫入及教練請求進行中，重新載入按鈕停用，等待請求完成；未儲存的草稿仍會在重載時清除，提示內明確說明。

點更新前再確認伺服器可連線，嘗試更新 SW，僅刪除 fit- 開頭靜態快取；不取消 SW 註冊、不刪推播訂閱、不呼叫登出、不改資料庫。以唯一 query 原地重新導覽至目前頁面。網路錯誤保留提示可重試。

提示內附：主畫面 App 點按鈕，若仍舊版再從多工完全關閉重開；手機 Safari／Chrome 可用選單重新載入；電腦 Ctrl+R／Mac Command+R，仍舊版用 Ctrl+Shift+R／Command+Shift+R。首次部署此功能前的舊版無偵測程式，使用者需先手動重載一次，此後的更新才自動提示。PWA 不能自行關閉 iOS App。

功能列預設隱藏，僅點螢幕上 84px 或下 96px 才叫出；中間內容點擊不叫出。鍵盤操作保留可及性入口，已開啟的功能列內操作延長 5 秒。

功能列喚出使用 click（不是 pointerdown），並排除內容區的按鈕、連結、輸入欄、選單與摘要等操作元件，避免其他使用者頁籤被浮層攔截。上／下緣空白區才觸發，功能列本身的操作仍可延長顯示。
目前已改用固定可見的上下把手（最小 44px 高）才喚出，不再使用邊緣點擊判定；8 秒無操作收起，也可手動收起。前述 84px／96px 邊緣喚出規則已停用。
