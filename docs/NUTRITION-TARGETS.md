# 訓練頁的熱量與營養目標

訓練頁點「設定我的目標」，讀取目前個人檔案。輸入公式性別、年齡、身高、體重、活動量，選減脂、維持／體態重組或增肌；目標體重、目前及目標體脂可選填。「計算」只做本機預覽；「套用到每日飲食目標」才由伺服器重算後寫入個人檔案。今日、飲食、小屋與教練下次讀取即使用新目標；不改舊飲食或訓練紀錄。

## 計算與假設

- 靜息代謝採 [Mifflin–St Jeor 原始研究](https://pubmed.ncbi.nlm.nih.gov/2305711/)，再乘活動係數 1.2–1.9 得維持熱量。係數是常見估算分級，不是個人代謝實測。
- 起始減脂缺口採維持量 10%、最多 300 kcal；增肌 +200 kcal，維持不加減。這些是產品的保守起始設定，不保證特定速度。活動係數已包含日常訓練，不再把運動消耗全數加回。
- 蛋白質以目前／目標兩者較低體重，維持 1.6、增肌 1.8、減脂 2.0 g/kg 起算，最高不超過熱量的 35%；脂肪約占 25%，其餘碳水。運動蛋白質範圍參考 [ISSN 2017 立場聲明](https://pmc.ncbi.nlm.nih.gov/articles/PMC5477153/)，特定分配為本專案設定。
- 熱量不低於估計靜息代謝，且本計算器採男性 1500、女性 1200 kcal 的程式下限；這不是適合所有人的安全保證或個人處方。
- 若未填目標體重而有填目標體脂，以 `目前體重 × (1 - 目前體脂) ÷ (1 - 目標體脂)` 推估參考體重，因此需要目前體脂。這是假設瘦體重不變，並非預測增肌結果。兩者都沒填時以目前體重為參考。
- 只填體態方向也能計算；填了體脂不改用另一套代謝公式。目標體脂用於追蹤與參考體重，不承諾指定外觀、局部減脂或達成日期。觀察 2–4 週趨勢再調整。
- 本功能供成人使用；未成年不產生此自動規劃。低體重者不提供減脂方案；程式不接受男性低於 10%、女性低於 18% 的體脂目標。這是產品支援範圍，沒有把這些界線當成所有人的臨床標準。懷孕、哺乳及治療性飲食應使用醫療團隊的個別目標。

## 資料與驗證

`shared/nutrition-targets.js` 是前後端共用公式；`PUT /api/profile/nutrition-targets` 忽略客戶端自填的計算結果，從身體資料重算。體重、目標體態及四項營養值沿用既有 profile 欄位，新增可為空的 `body_fat_pct`、`goal_body_fat_pct`。單一交易套用，跨帳號寫入禁止。舊資料庫只補欄位，不自動改任何人的既有目標。

UI 只有展開才抓個人檔案，避免每次進入訓練都多等一個請求。修改輸入會清除舊預覽，防止套用過期結果。既有教練或個人資料的重算仍可調整目標；想再次使用本計算方式可回到這張卡重新試算並套用。

測試涵蓋三種方向、每克能量加總、體脂推估、無效數據、低體重、伺服器重算、防跨帳號、原有紀錄保留及清空體脂。手機 320px 另驗證預覽不寫入、套用、重載後資料持續存在。
